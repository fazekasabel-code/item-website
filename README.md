# itemalapitvany.hu

Static website of the I.T.E.M. Kulturális és Oktatási Alapítvány. Plain HTML/CSS, generated by
one Python script (standard library only) and served by GitHub Pages from `docs/`.
The design and reasoning are in [ARCHITECTURE.md](ARCHITECTURE.md).

## Build

```bash
python3 build.py            # strict: fails if any text is missing in HU or EN
python3 build.py --draft    # allows missing translations (shows the source language instead)
python3 build.py --serve    # build, then preview on http://localhost:8000
python3 build.py --proof    # also writes proof/index.html: every text HU | EN side by side
```

Commit the regenerated `docs/` together with the content change. What is in `docs/` is what is live.

## Where things are

| What | Where |
|---|---|
| A project | `content/projects/<slug>/` – `meta.json` (facts), `hu.html` + `en.html` (text), images |
| Kijárat books | `content/books.json` + `content/covers/` |
| About, Contact | `content/pages/rolunk/`, `content/pages/kapcsolat/` |
| Address, legal data, funders | `content/site.json` |
| Interface texts (menus, labels) | `content/i18n.json` |
| Hungarian names → English order | `content/names.json` |
| Translation terminology | `content/glossary.json` |
| Page layouts | `templates/` (markup contract: `templates/README.md`) |
| Look | `assets/style.css` |
| Recovered old site, source images | `legacy/` (archive, not published) |

## Common tasks

- **Add a project:** copy a project folder, rename it (the folder name becomes the URL),
  edit `meta.json`, write `hu.html` and `en.html` paragraph by paragraph, add `logo.png` / `cover.jpg`
  if any, run `python3 build.py`, commit.
- **Add a book:** add an entry to `books.json` (newest first within a year) and its cover to
  `content/covers/`.
- **Finish a project:** `"status": "archived"`.
- **Approve a translation:** set `"proofread": {"hu": true, "en": true}` in that `meta.json`.
- **Rule:** a change to one language is always committed together with the other.

Body text may only use `p h2 h3 ul ol li a em strong br blockquote figure figcaption img`.
Links to other pages of the site are written root-relative (`/kijarat/`). The build adds `/en/` itself.
